# AI Dialog Manager

**One window for every AI coding assistant's chat history.**

Browse, search and **edit** sessions from **9 AI tools** (Claude Code, Codex,
OpenCode, Gemini CLI, Qwen Code, Goose, Cline, Roo Code, Kiro), and
**transplant** any conversation into another tool to continue it — new tool,
new working directory, zero context loss. Also exports self-contained,
zero-dependency "consciousness upload" bundles.

📦 Download the ready-to-run exe from
[Releases](https://github.com/haczen/ai-dialog-manage/releases) (Windows,
no Python needed).

📖 **Full documentation (in Chinese):** see the
[main README](https://github.com/haczen/ai-dialog-manage/blob/main/README.md).
